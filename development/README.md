# Библия вселенной — рабочая область

ВНИМАНИЕ: публичный репозиторий. Текущие материалы доступны всем. В будущем закрытые материалы нужно перенести в **отдельный private репозиторий**, не развёртываемый на GitHub Pages.

## Система статусов
- CANON — явно утверждено автором
- FAVORITE — фаворит поиска, не канон
- LIKED — вызывает симпатию
- DRAFT — на проработке
- QUESTION — открытый вопрос
- ARCHIVED — не используется сейчас

## Разделы
См. `data/world.json` — единый индекс разделов. Новые утверждения записываем в `development/decisions.md`; неизменяемый журнал решений позволяет различать версию замысла и канон.

## Принцип
Пока нет утверждённого канона мира; утверждён только процесс и выбор фаворита. Ключевые художественные детали требуют дальнейшей доработки.
