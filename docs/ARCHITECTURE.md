# Архитектура VSELEN 0.1

Статический сайт без платных зависимостей. Один источник начальных данных: `data/world.json`. Представление: `index.html`, `assets/css/styles.css`, `assets/js/app.js`.

## Публичная часть
Главная, Атлас, Хронология, Истории. Все публичные страницы впоследствии получат отдельные сущности, перекрёстные ссылки, карты, поиск и галереи.

## Разработка
Временно доступная вкладка #development отображает черновые данные. Это лишь интерфейсный режим, НЕ контроль доступа.

## Путь к приватной версии
1. Создать отдельный приватный репозиторий `Vselen-private` с внутренним каноном.
2. Не включать приватные материалы ни в сборку сайта, ни в публичную git-историю.
3. Публиковать в Vselen только одобренные и безопасные материалы через отдельный экспорт.
4. При необходимости делать внутренний веб-редактор с настоящей серверной авторизацией.
5. Не считать скрытый пункт меню или секретный URL защитой.

## Контент
Вся информация привязывается к статусу, источнику решения, версии и связанным сущностям. Изображения размещаются отдельно в `assets/images/` с сопровождающими описаниями.
