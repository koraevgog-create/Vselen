# VSELEN — авторская вселенная

Веб-атлас и рабочая Библия вселенной. Текущая концепция №19 **«Мир тысячи престолов»** — фаворит, но пока НЕ утверждённый канон.

## Структура
- `index.html` — сайт (GitHub Pages)
- `assets/css/styles.css` — оформление
- `assets/js/app.js` — навигация, поиск, визуализация данных
- `data/world.json` — реестр решений и концепций
- `development/` — рабочая документация
- `docs/` — архитектура и правила
- `assets/images/` — будущие изображения

## Приватность
⚠️ Репозиторий **публичный**. Всё внутри него, включая `development/`, доступно через GitHub! Скрытие вкладки в интерфейсе не является защитой. Для настоящей приватности перенести внутренние материалы в отдельный приватный репозиторий и закрытое приложение с авторизацией. GitHub Pages не предоставляет безопасную авторизацию для разделов статического сайта. Не помещать сюда спойлеры/секретные материалы для будущей франшизы.

## Запуск
Открыть `index.html` или включить GitHub Pages: Settings → Pages → Deploy from branch → main → /(root).

## Контент
Статусы: `canon` (утверждено), `favorite` (фаворит), `liked` (симпатия), `draft` (черновик), `rejected` (отклонено).
Все неопределённые детали помечаются как гипотезы. Решения из разговора нельзя автоматически объявлять каноном.
